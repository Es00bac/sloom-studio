# Illustrated crew source assets

These eight built-in imagegen illustrations adapt the actual production crew
captures from the canonical six-site Tideglass Baths map. They are illustrative
website artwork, distinct from the separately supplied game screenshots.

Each source PNG is 1024 × 1536 with genuine alpha. All full character silhouettes
were inspected for identity, outfit, readable limbs and uncropped feet/ears.
The optimized WebPs preserve the source alpha exactly and use color quality 88.
All eight characters are empty-handed for articulated mesh animation.

`crew-illustration-generation.json` retains exact prompts, references and image
metadata. `../assets/illustrated/crew-rig-landmarks.json` records manually fitted
normalized bind anchors for the website's triangular mesh skeletons, including
species-specific tails, ears, CyberPengu's tuft and Axi's six gill fans. Animation
implementation and final moving-page verification belong to the website lane.

These PNG originals and source records stay outside the published page bundle.
