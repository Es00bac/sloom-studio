# Origin website menu presentation

The site presentation uses the actual game main-menu artwork, controls, title
bitmap, and Unbounded/Barlow font families. The reference is the game screenshot
`Games/QindaOriginSpecies/validation/vulkan/menu-vk.png`. Source originals are
preserved beside this record; the public bundle uses optimized WebP copies.

## Source records

- `menu-theme-source-provenance.json`: exact qinda source paths, SHA-256 hashes,
  dimensions, alpha ranges and font licences.
- `menu-theme-original-art-prompts.json` and `menu-theme-original-art-notes.md`:
  the source game's artwork generation records.
- `menu-theme-wordmark-generation.json`: exact prompts and inspected references
  for the two new QOMPANY/SEEDWEB transparent raster titles. Each was generated
  once with the built-in imagegen tool. Both read correctly and have true alpha.
- `menu-theme-browser-qa.json`: actual native Firefox browser layout reports.

## Presentation and runtime boundaries

`index.html` and `origin.css` preserve navigation, world selectors, technology
selectors, both native video players/subtitle tracks, the motion control, all
thirteen illustrated cast files, all thirteen Tideglass production photos, the
structure manual and creator history. Cast labels use the neutral “Illustrated
cast” caption. The page can display intact source illustrations while articulated
animation receives a separate anatomy review. Rig and Seedweb runtime code and
configurations have their own owners.

## Physical Seedweb supports

The fabrication threshold has an illustrated architectural backdrop and a
visible metal/ceramic socket housing, capped conduit, overhead rail, mounting
ledge and menu-art outer frame. Five chassis stages each have a mounted coupler,
conduit, rail, ledge and outer frame. These elements use source control art and
CSS material geometry; no additional environments or character images were
generated for this transition.

Sources expose `data-seedweb-source`. Hardware exposes `data-seedweb-support`,
`data-support-kind`, painted width and (for frames) an inset. Ancestor networks
are named `threshold`, `scuttle`, `spool`, `chime`, `skip`, and `bastion`. Conduit
centerlines pass through source centers and meet the rail and ledge, so the
growth renderer can mount to actual measured hardware. Text and production
photos remain separate readable surfaces.
