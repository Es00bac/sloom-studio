# 設定

> 現在のマニュアル基準：**Sloom Studio ソース 0.9.16-b**（2026年8月27日検証）。表示される操作はプラットフォームとウィンドウ幅により異なり、ネイティブブリッジがない環境ではネイティブ専用操作を表示しません。

設定では、プロバイダー/モデル、インターフェース、暗号化バックアップ、セルフホスト型プロジェクトオーソリティ、ローカルクラッシュレポート、実行経路、ショートカット、ゲームパッド、管理フォント、Sloom Studio Proライセンスを扱います。

アプリケーションメニューまたは歯車ボタンから開きます。スマホでは主要領域がコンパクトなタブとして、デスクトップでは上部のボタンとして表示されます。

- **プロバイダー** — パック、インターフェース、キー、バックアップ、同期、診断、実行経路、既定モデル。
- **ショートカット** — 競合検査付きコマンド割り当て。
- **ゲームパッド** — ワークスペース別コントローラープロファイル。
- **フォント** — 管理対象オープンフォントライブラリ。
- **ライセンス** — Community/Pro状態とキー有効化。

## プロバイダーパックとモデルカード

個別の資格情報より先にProvider Pack Libraryがあります。パックは資格情報を含まず、プロバイダー経路と本番用モデルカードを記述します。同梱、ローカル、コミュニティ、プロジェクト埋め込みパックは同じ検証済みスキーマを使います。

利用手順：

1. インストール済みパックと、そのモデル/経路を確認します。
2. `.sloom-provider.json`を読み込みます。
3. 有効化前に、権限、エンドポイント、能力、入力操作、出力契約を確認します。
4. 必要ならModel Card Builderで視覚的に作成・編集します。
5. 資格情報を含まないパックを書き出して共有します。

読み込んだパックは、既存キーを密かに読む、エンドポイント規則を弱める、スキーマ検証に失敗するモデル能力を名乗ることはできません。詳しくは[プロバイダーパック/モデルカードガイド](../../userguide/14-provider-packs-model-cards.md)を参照してください。

## インターフェースと起動

インターフェース領域には次があります。

- **言語** — 英語/日本語。UIと関連既定値を変更し、既存文書の本文は翻訳しません。
- **最後のプロジェクトを起動時に再度開く** — デスクトップ専用。復旧/未保存文書保護を迂回しません。
- **テーマ** — 現在のダーク、高コントラスト、配色テーマ。
- **密度** — `コンパクト`または`快適`。
- **アプリメニュー表示** — 対応面で`コンパクト`または`メニューバー`。

テーマと密度は共有UIトークンを通して4ワークスペースへ適用されます。ドック/パネル配置は、別に名前付きワークスペースレイアウトへ保存されます。

### 保存状態と安全性

上部に表示される保存状態を確認し、すべての環境で同じ保護があると仮定しないでください。

- デスクトップは利用可能な場合にネイティブ安全保管エンベロープを使います。
- 対応するWeb/モバイル環境はWebCryptoエンベロープを使います。
- 安全な永続化が使えない場合、localStorageまたはメモリー限定の注意を明示します。
- アプリ起動中は復号した資格情報がメモリーに存在します。
- プロバイダーキーは、利用者が開始した操作のために設定済み経路だけへ送ります。

キーをプロジェクト、プロンプト、プロバイダーパック、ノードパック、サポートレポート、スクリーンショットへ入れないでください。共有ブラウザープロファイルでは資格情報を消去してください。

## 暗号化設定バックアップ

設定バックアップは平文JSONではなく、パスフレーズ暗号化エンベロープを書き出します。移植対象スキーマには資格情報、プロバイダー設定/既定値、インターフェース、メニュー表示、ロケール、キーボード/ゲームパッド、カスタムブラシ、フォントライブラリ、ライセンスキー、プロバイダーパック設定が含まれます。

書き出し：

1. **プロバイダー → 設定バックアップ**を開きます。
2. 強いパスフレーズを入力して確認します。
3. 暗号化バックアップを保存します。
4. パスフレーズを別の場所へ保管します。Sloom Studioは復旧できません。

復元：

1. 暗号化バックアップを選びます。
2. パスフレーズを入力します。
3. 結果を確認します。不正、未対応、復号不能データは失敗として止まります。
4. 別プラットフォームへ移した後は、プロバイダー/Vertex接続を再テストします。

バックアップは利用者が保存・コピーしたときだけ端末外へ出ます。暗号化済みでも重要な資格情報を含むため、慎重に扱ってください。

## Vertex AI認証

**Gemini資格情報モード**をVertex ADCにするとVertex認証パネルを表示します。現在は次を利用できます。

- デスクトップのGoogleブラウザーサインイン。
- 既存Application Default Credentialsの検出。
- ターミナル不要のADC authorized-user、workload-identity、service-account JSON読み込み。
- ファイルを選べない場合の資格情報JSON貼り付け。
- プロジェクト選択/手入力。
- 既知またはカスタム地域。
- 任意のクォータ/請求プロジェクト上書き。
- 接続テスト。

デスクトップは`gcloud`、読み込みADC、サービスアカウント、環境資格情報のどれが有効か報告します。モバイルは対応JSONを直接読み込みます。資格情報は保護設定ストアを使います。サービスアカウントファイルをリポジトリやプロジェクトへ含めないでください。

VertexはVertex対応モデル/経路を選んだときだけ使います。APIキー版Geminiは別の資格情報モードです。

## ランタイムオプション

対応環境では次を明示設定できます。

- OpenAI互換/Atlas Base URL。
- Gemini資格情報モードとVertex設定。
- Paper印刷アップスケール方法/PDFラスター設定。
- バッチ再試行回数と基準待機時間。
- ローカルレンダーバックエンド/書き出しコンポジター設定。
- ネイティブレンダーサービスURL/トークン。
- 任意バックエンドプロキシURLと有効化。
- ローカル/オープン画像エンドポイントと認証ヘッダー。
- Androidアクセラレーターのホスト、モデル、自己テスト。
- Android LANサーバー。

経路設定だけでは、サービス正常性やモデルの全能力を証明しません。隣接するテスト/状態操作を使い、小さな代表作業を実行してください。設定経路が失敗した場合はそのまま失敗し、別プロバイダーへ密かに課金しません。

## 既定モデル

文字、画像、動画、音声ごとにプロバイダー別既定モデル表があります。既定値は新規または未指定操作へ入力され、ノード/ツールに保存した明示モデルが優先します。

プロバイダー側のモデル一覧は変化します。資格情報/エンドポイント変更後は**カタログ更新**を使います。保存モデルが消えた場合は互換モデルを自分で選び、プロバイダーのフォールバックを同等とみなさないでください。

## 支出制御と料金表示

プロバイダーヘルプは必要設定と対応経路を説明します。モデル料金表は計画用推定で、請求書ではありません。現在の料金と利用可否はプロバイダーのアカウント/コンソールが正本です。

有料Flow実行では、Flowの強制支出上限が安全境界です。バッチ前に有限上限を設定してください。料金不明または上限超過の要求は、推定がないことを理由に通過せず明示的な解決を要求します。

## セルフホスト型プロジェクトオーソリティ

この領域では、**利用者が運用する**任意サービスを設定します。エンドポイントを入力して正常性を確認し、そのオーソリティへ登録/サインインします。

オーソリティはサーバー上にアカウントセッション、版管理プロジェクトBlob、上限付き復旧ログを保持します。Sloom提供クラウド、外部IDプロバイダー、インターネット継続保証、エンドツーエンド暗号化ではありません。リモート書き込みは明示的で版照合され、古い/オフライン端末は新しい版を密かに上書きできません。ブラウザーが永続保持するのはエンドポイントと上限付き再試行ジャーナルだけで、Bearerセッションはセッション限定です。

利用不可時はローカルプロジェクトを変更せず、リモート操作が失敗として止まります。信頼できないサービスを指定しないでください。

## クラッシュレポート

クラッシュ取得は任意でローカル限定です。有効にすると、構造的に秘匿処理されたレンダラー/メインプロセス報告とデスクトップminidumpを上限付きで保持します。自動送信せず、第三者クラッシュサービスを使いません。

- 新しいローカル取得の有効/無効。
- 保持報告の概要確認。
- 意図的共有用JSON書き出し。
- 確認後のローカル報告/minidump永久削除。

書き出した報告は送る前に確認してください。構造秘匿は資格情報露出を減らしますが、任意のプロジェクト文脈を公開してよいという意味ではありません。

## キーボードショートカット

ショートカット領域は共有ネイティブメニューコマンド登録を一覧表示します。コマンドを選び、対応キーコードを入力し、競合を確認します。グローバルまたはワークスペース限定の割り当てがあります。同じキーが文字入力に属するとき、ショートカットは発火しません。

**既定値へリセット**でカスタム割り当てを破棄します。移植には暗号化設定バックアップを使います。

## ゲームパッド

プロファイルはFlow、Image、Paper、Videoごとに保存します。ワークスペースと物理操作を選び、コマンド、対応する軸/デッドゾーン/感度/応答設定を割り当てます。既定値リセットは保存プロファイルへ適用されます。

## フォントライブラリ

フォント領域は対応オープンフォントを管理ライブラリへインストール/削除します。編集可能Paper文書と厳格印刷ではフォントの同一性と実バイトが重要です。同じファミリー名のシステムフォントは、管理文書の正確な代替と自動判断されません。

ダウンロード面は出典/ライセンス情報を保持します。ライセンスが許可するときだけパッケージ/再配布してください。

## ライセンス

ライセンス領域は**Community版**またはライセンス済み識別を表示します。Sloom Studio Pro有効化：

1. 正規Sloom購入経路から永久ライセンスを取得します。
2. **設定 → ライセンス**を開きます。
3. 完全なキーを貼り付け、**ライセンスを有効化**します。
4. ライセンス先識別が表示されたことを確認します。

検証はローカルで、失敗時はCommunity版に閉じます。不正、欠落、古い操作で置き換えられた、または検証不能なキーはProを有効にしません。有効キーを削除するとCommunity動作へ戻ります。

Sloom Studio Proは現在、Tiltmark V3、プロ印刷出力、ライセンス済み出力メタデータ、起動通知解除、商用利用ライセンスを提供します。Community版も4ワークスペースとStudio Brushを保持します。法的範囲は購入条件とリポジトリライセンスを確認してください。

## OSSライセンス

プロバイダー面にはパッケージ対象の第三者通知/ライセンスがあります。Sloom Studio再配布や別製品への部品組み込み前に確認してください。開発チェックアウトに部品があることだけでは、特定パッケージへの同梱を証明しません。

## 問題解決

| 症状 | 確認すること |
| --- | --- |
| キーが保持されない | 表示された安全保管状態を確認します。メモリー限定モードは意図的に保持しません。 |
| Unauthorized | キー、Base URL、組織/プロジェクト、地域、資格情報モードを確認し、接続テストします。 |
| 要求モデルがない | カタログ更新後、プロバイダー/モデルカードを確認し、互換モデルを明示選択します。 |
| Vertexを実行できない | 状態バッジの全ブロッカー、プロジェクト/地域/クォータを解決し、接続テストします。 |
| ローカルレンダー失敗 | ネイティブサービスURL/トークン、スクラッチフォルダー、Videoジョブの意味的エラーを確認します。 |
| セルフホスト同期が拒否 | 再サインインし、リモート版を調整します。版照合を迂回しません。 |
| バックアップ復元失敗 | ファイル、正確なパスフレーズ、元版を確認します。失敗時に元設定は変わりません。 |
| ショートカットが動かない | 競合、現在のワークスペース、文字入力フォーカス、OS予約キーを確認します。 |
| 管理フォントがない | 許可された正確な書体を再インストール/再リンクし、厳格出力で名前だけの代替を受け入れません。 |

パック作成は[プロバイダーパックガイド](../../userguide/14-provider-packs-model-cards.md)、復旧/サポート証拠は[問題解決と復旧](../../userguide/12-troubleshooting-and-recovery.md)を参照してください。
